## Featured Portfolio

### Game Design Portfolio

`game-portfolio/` presents three game-related projects as a compact portfolio:

- **Red Table Society**: narrative social simulation, systems design, GDD writing, and team collaboration.
- **Eternity**: Twine interactive narrative using branching structure, emotional pacing, and HTML/CSS/JavaScript interface work.
- **1943: The Battle of Midway**: game analysis essay focusing on arcade pacing, feedback systems, resource pressure, and player experience.

See [GitHub-HR-Setup.md](GitHub-HR-Setup.md) for the recommended profile, pinning, fork, and case-study setup.

For HR presentation, the best options are:

- Pin the team repositories on the GitHub profile if they are public and GitHub recognizes Allen as a contributor.
- Fork the repositories into `zhcao-ops` and clearly credit the original team repository.
- Add short case-study summaries in the profile README when the original repositories cannot be made public.

Recommended format:

```md
### Team Project Name
- Role: Narrative designer / front-end contributor / producer / researcher
- Contribution: Briefly list concrete work
- Repository: https://github.com/owner/repository
- Outcome: One sentence about the final result
```
