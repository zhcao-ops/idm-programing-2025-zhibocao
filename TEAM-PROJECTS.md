# Team Collaboration Projects

This page highlights two public team repositories that can be shared with HR as evidence of collaborative web development work. The original repositories remain under the team members' GitHub accounts, so this page acts as a clear index from Allen Zhibo Cao's own portfolio repository.

## Upthrift

Repository: [sheriglady-sg/Upthrift_Programming_Group-7](https://github.com/sheriglady-sg/Upthrift_Programming_Group-7)

**Project type:** full-stack second-hand marketplace / community platform

**Technology and structure**

- Node.js and Express backend
- MySQL database, with setup through XAMPP or local MySQL
- EJS views for server-rendered pages
- User authentication, password hashing, profile settings, posting flow, reviews, events, messages, and notifications
- Socket.IO-based real-time messaging, typing indicator, and notification updates
- File upload folders for profile images and message images
- Form validation with `express-validator`

**Why it is useful for HR**

This project shows experience working inside a larger collaborative codebase rather than a small static page. It includes user accounts, database-backed content, real-time interaction, file handling, validation, and multiple views/controllers/routes.

**Suggested profile description**

Collaborated on **Upthrift**, a full-stack second-hand marketplace project using Node.js, Express, MySQL, EJS, Socket.IO, file uploads, user authentication, and real-time messaging/notifications.

## Da Bao'en Porcelain Tower

Repository: [Kewusir/Da-Bao-en-Porcelain-Tower](https://github.com/Kewusir/Da-Bao-en-Porcelain-Tower)

**Project type:** cultural heritage / historical web experience

**Technology and structure**

- Multi-page static website built with HTML, CSS, and JavaScript
- Historical sections including ancient, medieval, classical, industrial, and present-day pages
- Visitor experience pages and interactive visitor map scripts
- Image lightbox interaction
- Multilingual content files such as `lang.js`, `lang-index.js`, `lang-learn-more.js`, and `lang-visitor-experience.js`
- 3D/model-related assets including `three.module.js`, `OBJLoader.js`, and `model.obj`
- Curated source and image-reference pages

**Why it is useful for HR**

This project shows collaborative front-end work on an information-rich cultural website. It combines content organization, multilingual presentation, visual assets, historical storytelling, navigation, interaction design, and web-based interpretation of a cultural site.

**Suggested profile description**

Collaborated on **Da Bao'en Porcelain Tower**, a cultural heritage website with multi-page historical storytelling, multilingual JavaScript content, image interactions, visitor experience pages, and 3D/model assets.
