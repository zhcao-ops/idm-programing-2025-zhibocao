# GitHub Setup for HR Sharing

This checklist explains how to make the portfolio easier for HR to view from the GitHub profile.

## 1. Repository Now Uploaded

The portfolio materials are uploaded here:

https://github.com/zhcao-ops/idm-programing-2025-zhibocao

Important paths:

- `README.md`: main repository introduction.
- `game-portfolio/`: game portfolio website, PDFs, and visual assets.
- `PROFILE-README-DRAFT.md`: profile README text to copy into the GitHub profile repository.

## 2. Enable GitHub Pages

GitHub Pages makes the HTML portfolio open as a normal website instead of source code.

Steps:

1. Open the repository:
   `https://github.com/zhcao-ops/idm-programing-2025-zhibocao`
2. Go to **Settings**.
3. Click **Pages** in the left sidebar.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **master**
   - Folder: **/ (root)**
5. Click **Save**.

After GitHub finishes publishing, the game portfolio should be available at:

`https://zhcao-ops.github.io/idm-programing-2025-zhibocao/game-portfolio/`

## 3. Create a GitHub Profile README

GitHub shows a profile README at the top of the profile page when a public repository has the exact same name as the username.

Steps:

1. Create a new public repository named exactly:
   `zhcao-ops`
2. Add a `README.md` file.
3. Copy the content from:
   `PROFILE-README-DRAFT.md`
4. Update the team project links once the two team repository URLs are known.

This will make the GitHub profile itself look like a portfolio landing page.

## 4. Show Team Collaboration Repositories

GitHub may not show repositories owned by classmates on the profile automatically. Use one of these methods:

### Option A: Pin the Team Repositories

Use this if the team repositories are public and GitHub recognizes the account as a contributor.

1. Go to `https://github.com/zhcao-ops`.
2. Click **Customize your pins**.
3. Search for each team repository.
4. Select them and save.

### Option B: Fork the Team Repositories

Use this if the repository is public but owned by another teammate.

1. Open the team repository.
2. Click **Fork**.
3. Fork it into `zhcao-ops`.
4. Add a README note crediting the original repository and team members.
5. Pin the fork on the profile.

### Option C: Create a Case Study Repository

Use this if the team repository is private or cannot be shared publicly.

Create a new public repository such as:

- `team-project-case-study-1`
- `team-project-case-study-2`

Include:

- project overview
- your role
- screenshots or public demo material
- concrete contributions
- team credit
- link to the original repository only if it is public or shareable

Do not upload private team code without permission.

## 5. Recommended HR Sharing Link

Once the profile README and pins are ready, share:

`https://github.com/zhcao-ops`

If GitHub Pages is enabled, also share:

`https://zhcao-ops.github.io/idm-programing-2025-zhibocao/game-portfolio/`
