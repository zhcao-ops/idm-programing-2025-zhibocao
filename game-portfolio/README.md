# Allen Zhibo Cao Game Portfolio

This folder contains Allen Zhibo Cao's game-related portfolio materials. It is designed for fast review by instructors, recruiters, and collaborators.

## Contents

- `index.html`: web version of the portfolio.
- `Allen-Zhibo-Cao-Game-Portfolio-Standalone.html`: single-file offline version with images embedded.
- `Allen-Zhibo-Cao-Game-Portfolio-Final-ZH.pdf`: Chinese PDF portfolio.
- `Allen-Zhibo-Cao-Game-Portfolio-Final-EN.pdf`: English PDF portfolio.
- `project-assets/`: visual assets used by the web portfolio.

## Projects Included

### Red Table Society

A narrative social simulation game concept set around a university canteen. The project combines rationing, trade, guessing, and trust variables to create a politically charged player experience.

**Contribution**

- Proposed the core concept and thematic direction.
- Wrote key sections of the Game Design Document.
- Designed variables such as Trust, Suspicion, Affection, Hidden Reserves, and Favor Debt.

### Eternity

A Twine-based interactive narrative about Elizabeth's life choices, relationships, pressure, and personal growth.

**Contribution**

- Built the story framework and character relationships.
- Structured the experience through Harlowe passage-based branching.
- Adjusted interface presentation using HTML, CSS, and JavaScript.

### 1943: The Battle of Midway

A game analysis essay examining Capcom's arcade shooter through pacing, feedback, resource pressure, visual rhythm, and historical framing.

**Contribution**

- Collected screenshot and mechanics evidence.
- Analysed level rhythm and enemy wave structure.
- Converted play experience into structured design critique.

## Suggested Viewing Order

1. Open the Chinese or English PDF for a clean presentation-style overview.

3. Use the standalone HTML file when sharing offline or when external hosting is unavailable.
